# Stem Test Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command scores a crate section's melodic stems after conversion (bass → Acid Bass pattern, guitar/other → My lil Roll text), keeps a baseline, and can load the parts into the open Rack patch for an ear A/B and put the patch back.

**Architecture:** A pure module (`tools/stem-score.mjs`) converts and scores; a CLI (`tools/stem-test.mjs`) finds the files, runs notegrab when needed, writes results and compares against the baseline; a small Rack client (`tools/rack.mjs`) talks to the Rack MCP over HTTP for `--load` / `--restore`. The reader itself (`tools/smf.mjs`) is not changed.

**Tech Stack:** Node ESM (`node --test`, `node:assert/strict`), the existing `tools/smf.mjs` reader and `tools/fixtures.mjs` MIDI writers, notegrab (Python venv in `~/dev/mcp-servers/my-lil-uvr-mcp`), the Rack MCP HTTP endpoint `http://127.0.0.1:2600/mcp`.

**Spec:** `docs/superpowers/specs/2026-11-22-stem-test-design.md` (commit fd0fa68, branch `feat/stem-test`).

**Repo facts the engineer needs:**
- Work in `C:\Users\Arikl\Desktop\_Projects\my-lil-acid-bassline` on branch `feat/stem-test`. The suite is `node --test` (133 tests pass on main before this plan).
- `loadCore()` from `tools/load.mjs` returns `{ T, X }`; `T` is the app core (`T.parsePattern(text)`, `T.patternsToMidi([pattern], bpm, name)` → bytes, `T.emptyPattern()`).
- `readSmf(bytes)` from `tools/smf.mjs` returns `{ ppq, bpm, notes }`, each note `{ start, end, note, vel, channel, track, startSec, endSec }`.
- `notesToPattern(notes, ppq, T, { steps, offset, gridBpm, startSec })` returns `{ pattern, report }`; in `gridBpm` mode it snaps on seconds (`ppq` unused) and `report.meanSnap` is the mean distance to the grid in steps. It throws `'no notes after --offset N'` / `'no notes inside the window (...)'` for an empty window.
- A step is `{ gate: 'note'|'tie'|'rest', note: 0-12, oct: -1..1, accent, slide }`; its MIDI note is `36 + note + 12 * oct`.
- `stemNotes(notes, bpm)` from `tools/fixtures.mjs` writes a basic-pitch-shaped `.mid` (`notes: [{ step, note, sec, vel }]`).
- My lil Roll text: `bars=N` then one `start len pitch vel` line per note; 96 PPQ, a bar = 384 ticks, a 16th = 24 ticks, max 16 bars. Roll keeps one note per start + pitch.
- Commits: author A_Development, normal prose, no AI attribution lines of any kind.

```js
// tools/stem-score.mjs — the stem test's pure half: where a stem's notes and a converted part's notes start (in 16th steps), and how
// well they match. A stem note is hit by a part note starting within half a step with the same pitch class (the reader folds octaves).
// Spec: docs/superpowers/specs/2026-11-22-stem-test-design.md
// Author: Ari Klopfer / A_Development · MIT

// readSmf notes -> [{ pos, note }]: pos is the onset in 16th steps at bpm (bpm / 15 steps a second), step 0 at startSec
export const stemOnsets = (notes, bpm, startSec = 0) => notes.map((n) => ({ pos: (n.startSec - startSec) * bpm / 15, note: n.note }));

// a step pattern's note-ons as [{ pos, note }], pos = offset + step. A note step slid into from the same pitch writes no note-on.
export function patternOnsets(p, offset = 0) {
  const out = [];
  for (let s = 0; s < p.len; s++) {
    const st = p.steps[s];
    if (st.gate !== 'note') continue;
    const midi = 36 + st.note + 12 * st.oct, prev = s > 0 ? p.steps[s - 1] : null;
    if (prev && prev.gate === 'note' && prev.slide && out.length && out[out.length - 1].note === midi) continue;
    out.push({ pos: offset + s, note: midi });
  }
  return out;
}

// F1 of part against stem. Each part note hits at most one stem note (stem notes taken in time order, first free match wins).
export function f1Score(stem, part) {
  const used = new Set();
  let hits = 0;
  for (const a of [...stem].sort((x, y) => x.pos - y.pos)) {
    const j = part.findIndex((b, i) => !used.has(i) && Math.abs(b.pos - a.pos) <= 0.5 && (b.note - a.note) % 12 === 0);
    if (j >= 0) { used.add(j); hits++; }
  }
  const p = part.length ? hits / part.length : 0, r = stem.length ? hits / stem.length : 0;
  return { f1: p + r ? 2 * p * r / (p + r) : 0, kept: hits, dropped: stem.length - hits, extra: part.length - hits };
}
```

```js
// The bass as an Acid Bass pattern: every 32-step window (offset 0, 32, 64, ...) read by notesToPattern at the song's tempo,
// each scored against the stem notes that snap into it; the best F1 wins, a tie goes to the earlier window.
// Returns { offset, pattern, report, score }.
export function bestBassWindow(notes, T, bpm, startSec = 0) {
  const on = stemOnsets(notes, bpm, startSec);
  const last = Math.max(...on.map((o) => Math.round(o.pos)));
  let best = null;
  for (let offset = 0; offset <= last; offset += 32) {
    let r;
    try { r = notesToPattern(notes, null, T, { steps: 32, offset, gridBpm: bpm, startSec }); }
    catch (e) { if (String(e.message).startsWith('no notes')) continue; throw e; }   // an empty window
    const stem = on.filter((o) => Math.round(o.pos) >= offset && Math.round(o.pos) < offset + 32);
    const score = f1Score(stem, patternOnsets(r.pattern, offset));
    if (!best || score.f1 > best.score.f1) best = { offset, pattern: r.pattern, report: r.report, score };
  }
  if (!best) throw new Error('no 32-step window holds a note');
  return best;
}
```

```js
const ROLL_16TH = 24, ROLL_BAR = 384, ROLL_MAX_BARS = 16;   // My lil Roll: 96 PPQ, 4/4, up to 16 bars

// A chord part as My lil Roll text: every note snapped to a 16th at bpm, at least a 16th long, one per start + pitch (Roll keeps
// one), velocity 0-1, the first 16 bars only. Returns { text, bars, score, meanSnap } (score: F1 against the stem's notes in those
// bars; meanSnap: their mean distance to the 16th grid, in steps).
export function rollPart(notes, bpm, startSec = 0) {
  const tick = (sec) => Math.round((sec - startSec) * bpm / 15) * ROLL_16TH;
  const rows = [], seen = new Set();
  for (const n of notes) {
    const s = tick(n.startSec);
    if (s < 0 || s >= ROLL_MAX_BARS * ROLL_BAR || seen.has(s + ':' + n.note)) continue;
    seen.add(s + ':' + n.note);
    rows.push([s, Math.max(ROLL_16TH, tick(n.endSec) - s), n.note, Math.round(n.vel / 127 * 100) / 100]);
  }
  if (!rows.length) throw new Error('no notes in the first 16 bars');
  const bars = Math.floor(Math.max(...rows.map((r) => r[0])) / ROLL_BAR) + 1;
  const stem = stemOnsets(notes, bpm, startSec).filter((o) => Math.round(o.pos) >= 0 && Math.round(o.pos) < bars * 16);
  const score = f1Score(stem, rows.map(([s, , note]) => ({ pos: s / ROLL_16TH, note })));
  const meanSnap = stem.reduce((a, o) => a + Math.abs(o.pos - Math.round(o.pos)), 0) / stem.length;
  return { text: 'bars=' + bars + '\n' + rows.map((r) => r.join(' ')).join('\n') + '\n', bars, score, meanSnap };
}
```

```js
const pct = (x) => Math.round(x * 100) + '%';
// the ear verdicts already typed into results.md, by part (column 10 of the table)
function earOf(path) {
  const ear = {};
  if (!existsSync(path)) return ear;
  for (const line of readFileSync(path, 'utf8').split(/\r?\n/)) {
    const c = line.split('|').map((x) => x.trim());
    if (c.length === 12 && TARGET[c[1]] && c[10]) ear[c[1]] = c[10];
  }
  return ear;
}
function table(res, ear) {
  const vs = (r) => r.change === null ? 'baseline' : (r.change >= 0 ? '+' : '') + r.change.toFixed(2) + (r.fail ? ' FAIL' : '');
  return '# stem test: ' + res.crate + ' ' + res.section + ' (' + res.date + ')\n\nFill `ear` with keep, close or bad.\n\n' +
    '| part | target | window | F1 | kept | dropped | extra | off grid | vs baseline | ear |\n|---|---|---|---|---|---|---|---|---|---|\n' +
    res.rows.map((r) => '| ' + [r.part, r.target, r.window ?? '-', r.f1.toFixed(2), r.kept, r.dropped, r.extra, pct(r.offGrid), vs(r),
      ear[r.part] || ''].join(' | ') + ' |').join('\n') + '\n';
}

async function main(argv) {
  const flags = argv.filter((a) => a.startsWith('--')), [crate, section, ...rest] = argv.filter((a) => !a.startsWith('--'));
  if (!crate || !section || rest.length || flags.length > 1 || (flags[0] && flags[0] !== '--load' && flags[0] !== '--restore')) throw new Error(USAGE);
  const out = join(UVR, 'notegrab', 'stem-test', crate + '-' + section);
  if (flags[0] === '--restore') { await restoreRack(out); return 0; }
  const dir = join(UVR, 'crates', crate);
  if (!existsSync(dir)) throw new Error('no crate folder ' + dir);
  const files = readdirSync(dir), esc = section.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');
  const { T } = loadCore();
  const rows = [];
  for (const [prefix, part] of PARTS) {
    const re = new RegExp('^' + prefix + '-' + esc + '-(\\d+(?:\\.\\d+)?)bpm\\.wav$', 'i');
    const f = files.find((x) => re.test(x));
    if (!f) { console.error('no ' + part + ' stem for ' + section + ': skipped'); continue; }
    const bpm = Number(re.exec(f)[1]), stem = f.replace(/\.wav$/i, ''), mid = join(UVR, 'notegrab', stem, stem + '.mid');
    notegrab(join(dir, f), mid);
    const notes = readSmf(readFileSync(mid)).notes.filter((n) => n.channel !== 9);   // channel 10 is drums
    mkdirSync(out, { recursive: true });
    if (part === 'bass') {
      const w = bestBassWindow(notes, T, bpm);
      writeFileSync(join(out, 'bass-acid.json'), JSON.stringify(w.pattern));
      rows.push({ part, target: TARGET[part], window: w.offset, ...w.score, offGrid: w.report.meanSnap });
    } else {
      const r = rollPart(notes, bpm);
      writeFileSync(join(out, part + '-roll.txt'), r.text);
      rows.push({ part, target: TARGET[part], window: null, ...r.score, offGrid: r.meanSnap });
    }
  }
  if (!rows.length) throw new Error('no bass, guitar or other stem for section ' + section + ' in ' + dir);

  const res = { crate, section, date: new Date().toISOString().slice(0, 10), rows };
  writeFileSync(join(out, 'results.json'), JSON.stringify(res, null, 2) + '\n');
  const basePath = join(out, 'baseline.json');
  const base = existsSync(basePath) ? JSON.parse(readFileSync(basePath, 'utf8')) : (copyFileSync(join(out, 'results.json'), basePath), null);
  let fails = 0;
  for (const r of rows) {
    const b = base && base.rows.find((x) => x.part === r.part);
    r.change = b ? r.f1 - b.f1 : null;
    r.fail = b ? b.f1 - r.f1 > DROP : false;
    if (r.fail) fails++;
  }
  const md = join(out, 'results.md'), text = table(res, earOf(md));
  writeFileSync(md, text);
  console.log(text + '\n' + out);
  if (flags[0] === '--load') await loadIntoRack(out);
  return fails ? 1 : 0;
}

main(process.argv.slice(2)).then((code) => { process.exitCode = code; }, (e) => { console.error(e.message); process.exitCode = 2; });
```

```js
// tools/rack.mjs — the stem test's Rack side, over the Rack MCP's HTTP endpoint (JSON-RPC tools/call). loadIntoRack writes the
// test parts into fixed slots (Acid Bass slot index 4 = I-A5, Roll patterns 15 and 16) and patches Roll into Triple, after saving
// what it changes to before.json; restoreRack puts that back. No other slot or cable is touched.
// Spec: docs/superpowers/specs/2026-11-22-stem-test-design.md
// Author: Ari Klopfer / A_Development · MIT
import { existsSync, readFileSync, renameSync, writeFileSync } from 'node:fs';
import { join } from 'node:path';

export const RACK_URL = process.env.RACK_MCP_URL || 'http://127.0.0.1:2600/mcp';
const ACID_SLOT = 4, ROLL_SLOT = { other: 15, guitar: 16 };

export async function rack(name, args = {}, url = RACK_URL) {
  let res;
  try {
    res = await fetch(url, {
      method: 'POST', signal: AbortSignal.timeout(30000),
      headers: { 'content-type': 'application/json', accept: 'application/json, text/event-stream' },
      body: JSON.stringify({ jsonrpc: '2.0', id: 1, method: 'tools/call', params: { name, arguments: args } }),
    });
  } catch (e) {
    if (e.name === 'TimeoutError') throw new Error(name + ': Rack did not answer in 30 s');
    throw new Error('open the patch in Rack first (no Rack MCP at ' + url + ')');
  }
  const j = JSON.parse(await res.text());
  const text = j.result && j.result.content && j.result.content[0] ? j.result.content[0].text : '';
  if (j.error || (j.result && j.result.isError)) throw new Error(name + ' failed: ' + (text || JSON.stringify(j.error) || 'see the Rack log'));
  try { return JSON.parse(text); } catch { return text; }
}

async function modules() {
  const mods = await rack('vcvrack_list_modules');
  const id = (slug) => { const m = mods.find((x) => x.slug === slug); if (!m) throw new Error('no ' + slug + ' module in the open patch'); return m.id; };
  return { acid: id('AcidBass'), roll: id('Roll'), triple: id('Triple') };
}
const tripleInputs = async (ids) => (await rack('vcvrack_list_cables')).filter((c) => c && c.inputModuleId === ids.triple && c.inputId <= 1);
// Rack's moduleFromJson needs plugin and model; sending data alone leaves the knobs as they are
const setData = (m, data) => rack('vcvrack_set_module_state', { id: m.id, state: { id: m.id, plugin: m.plugin, model: m.model, version: m.version, data } });

export async function loadIntoRack(out) {
  const ids = await modules(), before = join(out, 'before.json');
  const acid = await rack('vcvrack_get_module_state', { id: ids.acid }), roll = await rack('vcvrack_get_module_state', { id: ids.roll });
  if (!existsSync(before)) writeFileSync(before, JSON.stringify({ ids, acid, roll, tripleInputs: await tripleInputs(ids) }));   // the first backup is the real one
  const bass = join(out, 'bass-acid.json');
  if (existsSync(bass)) {
    const patterns = acid.data.patterns.slice();   // every slot, in order: a missing slot would load empty
    patterns[ACID_SLOT] = JSON.parse(readFileSync(bass, 'utf8'));
    await setData(acid, { ...acid.data, patterns });
  }
  const patterns = roll.data.patterns.slice();
  for (const [part, slot] of Object.entries(ROLL_SLOT)) {
    const f = join(out, part + '-roll.txt');
    if (existsSync(f)) patterns[slot - 1] = readFileSync(f, 'utf8');
  }
  await setData(roll, { ...roll.data, patterns });
  const now = await tripleInputs(ids);
  for (const c of now) if (c.outputModuleId !== ids.roll || c.outputId !== c.inputId) await rack('vcvrack_delete_cable', { id: c.id });
  for (const i of [0, 1])   // Roll V/OCT -> Triple V/OCT, Roll GATE -> Triple GATE
    if (!now.some((c) => c.outputModuleId === ids.roll && c.outputId === i && c.inputId === i))
      await rack('vcvrack_add_cable', { outputModuleId: ids.roll, outputId: i, inputModuleId: ids.triple, inputId: i });
  console.error('loaded: Acid Bass I-A5, Roll 15 (other) and 16 (guitar), Roll patched into Triple. Undo with --restore.');
}

export async function restoreRack(out) {
  const before = join(out, 'before.json');
  if (!existsSync(before)) throw new Error('nothing to restore: no ' + before);
  const saved = JSON.parse(readFileSync(before, 'utf8')), ids = await modules();
  if (['acid', 'roll', 'triple'].some((k) => ids[k] !== saved.ids[k])) throw new Error('the open patch is not the one in ' + before + ' (module ids differ)');
  await setData(saved.acid, saved.acid.data);
  await setData(saved.roll, saved.roll.data);
  for (const c of await tripleInputs(ids)) await rack('vcvrack_delete_cable', { id: c.id });
  for (const c of saved.tripleInputs)
    await rack('vcvrack_add_cable', { outputModuleId: c.outputModuleId, outputId: c.outputId, inputModuleId: c.inputModuleId, inputId: c.inputId });
  renameSync(before, join(out, 'before.restored-' + new Date().toISOString().replace(/[:.]/g, '-') + '.json'));
  console.error('restored Acid Bass, Roll and Triple\'s inputs from ' + before);
}
```
